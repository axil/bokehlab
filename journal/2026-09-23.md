# BokehLab 0.3.0 release updates

## Implemented

- Bumped the package and runtime version from `0.2.10` to `0.3.0` in the
  project metadata, package module, and lockfile.
- Hardened the browser smoke test for JupyterLab by waiting for a kernel that
  is both idle and connected to the frontend before executing the first cell.
- Hardened notebook output synchronization by waiting for output markers to be
  attached to the page rather than requiring them to be visible in the current
  viewport.
- Sequenced Classic Notebook execution so the BokehLab magic cell completes
  before the first plotting cell, while the remaining independent smoke cells
  still run as a batch.
- Added the release entry to `whatsnew.txt`.

## Verification

- JupyterLab with inline resources passed locally in the isolated CI-style
  environment: `PASS lab / inline`.
- Classic Notebook 6.5.7 with local-development resources passed locally:
  `PASS classic / local-dev`.
- The Python test suite passed with 67 tests.
- Python compilation and `git diff --check` passed.
